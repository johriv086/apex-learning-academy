# Apex Learning Academy — Portfolio Demo

A responsive React + Vite + Tailwind CSS website concept for a fictional learning institute. This is a portfolio demonstration, not a real institute website.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed in Terminal (usually http://localhost:5173).

## Create a production build

```bash
npm run build
npm run preview
```

## Important before using for a real business

- Replace fictional institute details, program information, testimonials and imagery with client-approved content.
- The enquiry form currently demonstrates client-side interaction only. It does not send or store submissions. Connect it to a backend or form service before launch.
- Add the client's real contact information, privacy notice and any required policies.
